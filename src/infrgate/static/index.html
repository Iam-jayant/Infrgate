About InfrGate

InfrGate is an open-source, high-performance AI Gateway designed to seamlessly multiplex and route traffic to various LLM providers (including OpenAI, Google Gemini, and Hugging Face) using a unified OpenAI-compatible API layer.

Why it is needed?

As organizations scale their AI usage, managing API keys, rate limits, and billing across disparate providers becomes a nightmare. InfrGate solves this by acting as a centralized proxy. Instead of distributing sensitive provider API keys to client applications, clients are given a Tenant API Key. InfrGate securely manages the upstream keys and enforces tenant-specific spending caps and rate limits.

Core Design Principles

This project was built adhering to strict distributed systems principles:

  • Atomicity: Background ledger updates ensure that token accounting is never lost, even if the primary request thread dies mid-stream.
  • Reliability: Robust failover logic catches HTTP timeouts and provider rate limits gracefully.
  • Observability: Real-time traces make debugging API issues transparent and deterministic.
  • Horizontal Scalability: Redis and PostgreSQL architecture ensures InfrGate can be scaled across multiple containers without locking contention.

How it works

When you send a message via the UI, the request undergoes a rigorous, optimized lifecycle:

  • Authentication: Validates the Tenant API key against PostgreSQL.
  • Rate Limiting: Enforces RPM and TPM limits using a fast Redis token bucket algorithm.
  • Idempotency Cache: Checks if the exact request was already processed to prevent duplicate billing.
  • Provider Routing: Dynamically selects the appropriate model adapter (e.g., translating OpenAI schema to Hugging Face or Gemini native schemas).
  • Response Streaming: Streams Server-Sent Events (SSE) back to the client in real-time.
  • Usage Accounting: Persists the final token counts to a secure Ledger using a highly concurrent SKIP LOCKED background worker, ensuring atomicity.
